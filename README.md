# מונה

אפליקציית PWA שמחשבת את המחיר החוקי של נסיעה במונית מיוחדת בישראל, לפי צו פיקוח על מחירי מצרכים ושירותים (מחירי נסיעה במוניות), התשע"ח–2018, כפי שתוקן ב-30.3.2026 (בתוקף מ-1.4.2026).

## מבנה
- `index.html` — המסכים (מחשבון, מונה חי, תעריפים)
- `src/engine.js` — מנוע החישוב: זיהוי תעריף לפי תאריך ושעה, פיצול נסיעה בין תעריפים, תוספות, מע"מ, מונה חי
- `src/hebcal.js` — לוח שנה עברי לזיהוי ימי מנוחה וערבי חג (ללא ספריות חיצוניות)
- `src/data/tariffs.json` — התעריפים מהצו, עם תאריכי תוקף (הוראת שעה עד 31.3.2027, ואחריה הסט הקבוע)
- `build.mjs` — בונה גרסה בקובץ יחיד לתיקיית `dist/`
- `tests/run.mjs` — בדיקות: `npm test`

## עדכון תעריפים
כל 1 באפריל משרד התחבורה מפרסם הודעת עדכון. מעדכנים את `src/data/tariffs.json` (מוסיפים סט חדש עם `valid_from`) ומריצים `npm test`.
